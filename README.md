# Тестовое задание: Клиент-серверная передача файлов по TCP (C++)

Консольные приложения на C++ (Linux) для передачи и приёма файлов по сети.

## Особенности реализации
* Сетевое взаимодействие: Использование системных сокетов TCP/IP (IPv4).
* Многопоточность: Сервер обрабатывает каждое подключение клиента в отдельном потоке (std::thread).
* Надежность: Реализована атомарная запись файлов через временное расширение .tmp. На диск сохраняется только полностью переданный файл.
* Настраиваемость: Настройка порта (-p), размера чанка (-chunk) и путей (-src, -dst) через аргументы командной строки.
* Поддержка режимов: Поддерживается как скачивание файла с сервера, так и отправка файла от клиента на сервер.

## Требования для сборки
* OS Linux
* Компилятор g++ с поддержкой стандарта C++11 и библиотеки pthread

## Сборка проекта

Сборка выполнена через g++ без сторонних зависимостей:

g++ -std=c++11 -pthread server.cpp -o server
g++ -std=c++11 -pthread client.cpp -o client

## Инструкция по запуску

### 1. Запуск сервера
По умолчанию сервер запускается на порту 4040:
./server

Указать конкретный порт для прослушивания:
./server -p 4040

### 2. Запуск клиента

Скачивание файла с сервера (DOWNLOAD):
./client -p 4040 -chunk 1024 -src 127.0.0.1:remote_file.txt -dst local_file.txt

Отправка файла на сервер (UPLOAD):
./client -p 4040 -chunk 512 -src local_file.txt -dst 127.0.0.1:remote_file.txt

Примечание: Если параметры -p или -chunk не указаны, используются значения по умолчанию (порт 4040, размер чанка 1024 байт).
